## L1 ↔ L2 Bridge Flow

### Deposits (L1 → L2)

```
User                    L1 Bridge              Sequencer              L2
 │                          │                      │                   │
 │  1. deposit(amount)      │                      │                   │
 │ ─────────────────────►   │                      │                   │
 │                          │                      │                   │
 │                          │  2. ETHDepositInit   │                   │
 │                          │     event emitted    │                   │
 │                          │ ────────────────────►│                   │
 │                          │                      │                   │
 │                          │                      │  3. poll events   │
 │                          │                      │ ──────────────────│
 │                          │                      │                   │
 │                          │                      │  4. enqueue       │
 │                          │                      │     L2Message     │
 │                          │                      │ ──────────────────│
 │                          │                      │                   │
 │                          │                      │  5. process       │
 │                          │                      │     deposit       │
 │                          │                      │ ──────────────────►
 │                          │                      │                   │
 │                          │                      │      6. credit    │
 │ ◄────────────────────────────────────────────────────────────────── │
 │         user can spend on L2                    │                   │
```

### Withdrawals (L2 → L1)

```
User                    L2 Precompile          Sequencer              L1 Bridge
 │                          │                      │                      │
 │  1. call 0x4200          │                      │                      │
 │     (withdrawal msg)     │                      │                      │
 │ ─────────────────────►   │                      │                      │
 │                          │                      │                      │
 │                          │  2. enqueue          │                      │
 │                          │     L2Message        │                      │
 │                          │ ────────────────────►│                      │
 │                          │                      │                      │
 │                          │                      │  3. include in      │
 │                          │                      │     batch           │
 │                          │                      │ ─────────────────────│
 │                          │                      │                      │
 │                          │                      │  4. submit batch    │
 │                          │                      │     + state root    │
 │                          │                      │ ────────────────────►│
 │                          │                      │                      │
 │                          │                      │  5. finalize        │
 │                          │                      │     withdrawals     │
 │                          │                      │ ────────────────────►│
 │                          │                      │                      │
 │  6. claim on L1          │                      │                      │
 │ ────────────────────────────────────────────────────────────────────► │
 │                          │                      │                      │
```

## Summary: Where Each Component Lives

| Layer | Component | Purpose |
|-------|-----------|---------|
| **AI Layer** | LLM APIs | Reasoning, planning, tool selection |
| **SDK Layer** | Guardrails | Spending limits, policies, allowlists |
| **SDK Layer** | Identity | DID generation, sessions, capabilities |
| **SDK Layer** | Payments | x402, escrow, direct transfers |
| **SDK Layer** | Activity Log | Audit trail, compliance |
| **Node Layer** | TxPool | Classification, routing |
| **Node Layer** | EVM | Standard execution |
| **Node Layer** | Precompiles | SVM Router, L2 Message Passer |
| **Node Layer** | Sequencer | Block production, batch submission |
| **L1 Layer** | Contracts | Data availability, bridging |
